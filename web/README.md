# Web Client

This folder contains the frontend for MiniBoss.

## Overview

The web client provides the UI for projects, conversations, focus workflows, approvals, and live updates. It communicates with the backend through REST and Socket.IO.

## Development

Install dependencies:

```bash
npm install
```

Start the dev server:

```bash
npm run dev
```

The default dev port is `5300`.
