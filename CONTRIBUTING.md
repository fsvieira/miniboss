# Contributing

Thanks for your interest in contributing to MiniBoss.

## Getting started

1. Fork and clone the repository.
2. Run `npm install` in `server/` and `web/` as needed.
3. Create a branch for your change.
4. Keep changes focused and minimal.
5. Open a pull request with a clear description and rationale.

## Guidelines

- Follow the existing code style.
- Do not add secrets, local `.env` values, or local database files.
- Update docs when behavior or setup changes.
- If in doubt, ask before implementing large refactors.
